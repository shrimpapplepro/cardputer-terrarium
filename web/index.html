Terrarium for the Cardputer ADV

Install from your browser: no toolchain, no drivers, no download-mode button.

Install

  1. Plug the Cardputer ADV into this computer with a USB-C data cable and switch it on.
  2. Click the button and pick the serial device that appears (an "USB JTAG/serial debug unit" or "Espressif").
  3. Wait about a minute. The board restarts into the tank by itself.

This browser can't talk to serial devices. Use desktop Chrome, Edge or Opera.

Read this first

This writes the whole flash (bootloader, partition table, app). It replaces an M5Launcher install and every app stored in its slots. If you use the Launcher, install through it instead: copy terrarium-adv-…-app.bin from the latest release to the SD card.

Nothing here needs Wi-Fi credentials, an account or internet access on the device. The tank only listens to nearby Wi-Fi/Bluetooth signals as a source of randomness; nothing is stored or sent.

Trouble?

  • No device in the list: try another cable or port; some cables are charge-only.
  • Linux: add yourself to the dialout group (or uucp) and log in again.
  • Windows: if the port never shows up, install the USB-Serial/JTAG driver.
  • Command line or building from source: see the README.
